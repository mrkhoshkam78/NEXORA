# Nexora V1 — One-Click Windows Edition

Nexora is a local-first Cloudflare Workers AI coding assistant.

## Windows one-click launch

Run `START-NEXORA.bat`.

You do NOT need Git, npm, Python, Wrangler, or a separately installed Node.js runtime. On first run the launcher downloads the tested Node.js 22.16.0 Windows x64 runtime into `%APPDATA%\Nexora\runtime`, then starts Nexora and opens the browser.

## Cloudflare setup

Enter your Cloudflare Account ID and API Token in the Nexora Setup Wizard. Credentials stay in the local backend and are encrypted with AES-256-GCM. They are never sent to browser JavaScript.

## V1 features

- Cloudflare Workers AI connection wizard
- Model discovery and primary/fallback selection
- Real AI connectivity test
- Qwen 3.8 27B preference when available
- Coding chat + tool calls
- Project ZIP import without Python/system ZIP
- Project tree + file editor
- AI file operations
- Search/analyze tools
- Real ZIP export generated by Nexora itself
- Model failure vs quota/rate-limit distinction

## Notes

The Windows launcher uses the official Node.js distribution URL for the fixed 22.16.0 x64 runtime. The runtime is downloaded only on the first launch and is kept locally for subsequent launches.
